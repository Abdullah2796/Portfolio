## Featured projects

### Vendor SLA & Procure-to-Pay Analytics (SQL)
[View Project](https://github.com/Abdullah2796/vendor-sla-p2p-sql) · PostgreSQL · CTEs · window functions

Nine SQL analyses on 12,500 incidents, 1,400 purchase orders and 1,500 invoices for a fictional IoT operator: monthly SLA trends with rolling averages, quarterly vendor rankings, repeat-fault detection with `LAG`, a running open-backlog, P90 resolution benchmarks, PO-to-payment cycle times, a spend Pareto and a "gaps and islands" SLA streak analysis.

### Smart-Meter Rollout Analytics (Power BI)
[View Project](https://github.com/Abdullah2796/lumora-grid-rollout) · Power Query · star schema · DAX

End-to-end Power BI project: six messy sources cleaned in Power Query with a data-quality log, a star schema with four fact tables and 42 DAX measures, including a run-rate year-end forecast and a KPI scorecard. Saved as PBIP for version control.

### Incident & SLA Analytics (Power BI)
[View Project](https://github.com/Abdullah2796/veyra-incident-sla) · ITSM data · DAX

An ITSM-style incident export joined to SLA policy, resolver, site and customer-satisfaction data: response and resolution SLA by priority, shift and vendor, P90 resolution time, backlog ageing, and the link between resolution speed and CSAT.
